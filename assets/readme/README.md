# Galeri README

Gambar ini merupakan tangkapan render halaman Flutter YUDHA pada 10 September 2026. Data berasal dari fixture pengujian widget, bukan akun pengguna atau respons layanan production. Tidak ada gambar antarmuka yang dibuat dengan AI.

| File | Halaman | Sumber data contoh |
|---|---|---|
| `learning.png` | Learning Center | `learning_page_test.dart`, rekomendasi TIU Numerik |
| `practice.png` | Solo Setup | `solo_setup_page_test.dart`, rekomendasi TIU Figural |

Saat memperbarui screenshot, gunakan halaman aplikasi yang bersangkutan dengan data demo, tunggu font dan gambar selesai dimuat, lalu periksa keterbacaan sebelum mengganti PNG. Pertahankan nama file agar tautan README tetap berlaku.
